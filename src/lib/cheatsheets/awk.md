# awk 치트시트

awk 는 입력을 줄과 필드로 나눠 패턴에 맞는 줄마다 동작을 실행한다.

필드 구분은 기본으로 연속 공백이다. 변수는 선언 없이 쓴다. 처음 값은 빈 문자열이고 수로는 0 이다.

## 구조

```bash
awk 'pattern { action }' 파일
awk 'BEGIN { print "시작" } { print $1 } END { print NR " 줄" }' 파일
awk -F',' '{ print $2 }' data.csv       # 구분자 지정
awk -v n=3 '{ print $n }' 파일           # 셸 값 넘기기
awk -f script.awk 파일                   # 스크립트 파일로 실행
```

| 꼴 | 뜻 |
| --- | --- |
| `pattern { action }` | 패턴에 맞는 줄에 동작 실행 |
| `pattern` | 동작을 비우면 `{ print }` 와 같다 |
| `{ action }` | 패턴을 비우면 모든 줄에 실행 |
| `BEGIN { … }` `END { … }` | 첫 줄 읽기 전 · 마지막 줄 뒤에 한 번 |
| `-F 구분자` | 입력 필드 구분자 (`-F','`, `-F'\t'`, `-F'[:,]'` 는 정규식) |
| `-v 이름=값` | 변수를 미리 설정 (셸 변수를 넘길 때) |

## 필드 · 내장 변수

| 변수 | 뜻 |
| --- | --- |
| `$0` | 줄 전체 |
| `$1` `$2` | 첫째 · 둘째 필드 |
| `$NF` `$(NF-1)` | 마지막 · 끝에서 둘째 필드 |
| `NF` | 현재 줄의 필드 수 |
| `NR` | 지금까지 읽은 줄 번호 (파일 여럿이면 이어서 센다) |
| `FNR` | 현재 파일 안의 줄 번호 |
| `FS` `OFS` | 입력 · 출력 필드 구분자 (`BEGIN { FS=","; OFS="\t" }`) |
| `RS` `ORS` | 입력 · 출력 줄 구분자 |
| `FILENAME` | 현재 파일 이름 |

## 조건(패턴)

| 패턴 | 뜻 |
| --- | --- |
| `/re/` | 줄에 정규식 re 가 있다 (`!/re/` 는 없다) |
| `$1 ~ /re/` | 1 번 필드가 re 에 맞다 (`!~` 는 맞지 않다) |
| `$1 == "x"` | 문자열 비교 (`!=`) |
| `$3 > 100` | 수 비교 (`<` `<=` `>=`) |
| `NR > 1` | 첫 줄(헤더) 건너뛰기 |
| `NR % 2 == 0` | 짝수 줄 |
| `NF` | 필드가 있는 줄 (빈 줄 제외) |
| `/start/,/end/` | start 줄부터 end 줄까지 |
| `A && B` `A \|\| B` `!A` | 그리고 · 또는 · 아니다 |

## 함수

| 함수 | 뜻 |
| --- | --- |
| `length(s)` | 길이 (`length($0)` 은 줄 길이, `length(a)` 는 배열 크기) |
| `substr(s, i, n)` | i 번째부터 n 글자 (1 부터 센다) |
| `index(s, t)` | s 에서 t 의 위치, 없으면 0 |
| `split(s, a, sep)` | s 를 sep 으로 나눠 배열 a 에 넣고 개수를 돌려준다 |
| `sub(re, r)` | 첫 일치를 r 로 바꾼다 (`sub(re, r, s)` 는 s 에서) |
| `gsub(re, r)` | 모든 일치를 r 로 바꾼다 |
| `toupper(s)` `tolower(s)` | 대문자 · 소문자로 |
| `sprintf(fmt, …)` | 형식 문자열을 만들어 돌려준다 |
| `int(x)` | 정수 부분 |
| `system("cmd")` | 셸 명령 실행 |

## 배열

| 꼴 | 뜻 |
| --- | --- |
| `a["k"] = v` | 연관 배열 (키는 문자열) |
| `a[$1]++` | 1 번 필드 값마다 개수 세기 |
| `sum[$1] += $3` | 1 번 필드 값마다 3 번 필드 합계 |
| `for (k in a)` | 키 순회 (순서는 정해져 있지 않다) |
| `if ("k" in a)` | 키 확인 (새 원소를 만들지 않는다) |
| `delete a["k"]` `delete a` | 원소 삭제 · 전체 삭제 |

## 제어

| 꼴 | 뜻 |
| --- | --- |
| `if (c) … else …` | 조건 |
| `for (i = 1; i <= NF; i++)` | 반복 |
| `while (c)` | 반복 |
| `break` `continue` | 반복 중단 · 다음 반복으로 |
| `next` | 현재 줄을 끝내고 다음 줄로 |
| `exit` | 입력 읽기를 끝낸다 (END 는 실행된다) |
| `getline` | 다음 줄을 직접 읽는다 (`"cmd" \| getline v` 는 명령 출력을 v 에) |

## 출력

| 꼴 | 뜻 |
| --- | --- |
| `print` | `$0` 출력 |
| `print $1, $3` | 쉼표는 OFS 로 잇는다 (`print $1 $3` 은 붙여 쓴다) |
| `print $1 "\t" $3` | 문자열을 끼워 출력 |
| `printf "%-10s %5d\n", $1, $2` | 형식 출력 (왼쪽 정렬 10 칸, 정수 5 칸) |
| `printf "%.2f\n", x` | 소수 둘째 자리까지 |
| `print > "out.txt"` | 파일에 쓰기 (첫 번은 덮어쓰기, 이후는 이어쓰기) |
| `print \| "sort -n"` | 명령에 넘기기 (끝내려면 `close("sort -n")`) |

## 자주 쓰는 한 줄

| 명령 | 뜻 |
| --- | --- |
| `awk '{ print $1, $3 }' 파일` | 1 · 3 열 출력 |
| `awk '{ print $NF }' 파일` | 마지막 열 |
| `awk -F',' '{ print $2 }' data.csv` | CSV 2 열 (따옴표 안의 쉼표는 못 다룬다) |
| `awk -F',' -v OFS='\t' '{ $1 = $1; print }' data.csv` | CSV → TSV |
| `awk '{ sum += $3 } END { print sum }' 파일` | 3 열 합계 |
| `awk '{ sum += $3 } END { print sum / NR }' 파일` | 3 열 평균 |
| `awk 'NR > 1' 파일` | 헤더 건너뛰기 |
| `awk 'END { print NR }' 파일` | 줄 수 |
| `awk '!seen[$0]++' 파일` | 중복 줄 제거 (순서 유지, `!seen[$1]++` 는 1 열 기준) |
| `awk '$3 > 100' 파일` | 3 열이 100 보다 큰 줄 |
| `awk '$1 == "ERROR"' app.log` | 1 열이 ERROR 인 줄 |
| `awk '/start/,/end/' 파일` | 두 패턴 사이 줄 |
| `awk 'NF' 파일` | 빈 줄 제거 |
| `awk '{ $1 = $1; print }' 파일` | 공백 정리 (연속 공백을 하나로) |
| `awk '{ print $2, $1 }' 파일` | 열 순서 바꾸기 |
| `awk '{ a[$1]++ } END { for (k in a) print k, a[k] }' 파일` | 1 열 값별 개수 |
| `awk 'NR == FNR { a[$1] = $2; next } $1 in a { print $0, a[$1] }' f1 f2` | 1 열 기준으로 두 파일 조인 |
| `ps aux \| awk '$3 > 50 { print $2, $11 }'` | CPU 50% 넘는 프로세스 (PID, 명령) |

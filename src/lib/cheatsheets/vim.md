# vim 치트시트

vim 에서 자주 쓰는 키와 명령을 모았다.

`:` 로 시작하는 명령은 normal 모드에서 입력한다. 키 앞에 숫자를 붙이면 그만큼 반복한다. 예: `3dd` 는 세 줄을 지운다.

## 모드

| 키 | 뜻 |
| --- | --- |
| `Esc` | normal 모드로 돌아간다 |
| `i` `a` `o` | insert 모드 (커서 앞 · 커서 뒤 · 아래 새 줄) |
| `v` `V` `Ctrl-v` | visual 모드 (글자 · 줄 · 블록) |
| `:` | command 모드 (`:w`, `:q`, `:s` 같은 명령) |

## 이동

| 키 | 뜻 |
| --- | --- |
| `h` `j` `k` `l` | 왼쪽 · 아래 · 위 · 오른쪽으로 한 칸 |
| `w` `b` `e` | 다음 단어 처음 · 이전 단어 처음 · 단어 끝 |
| `0` `^` `$` | 줄 처음 · 줄의 첫 글자 · 줄 끝 |
| `gg` `G` | 파일 처음 · 파일 끝 |
| `:n` `nG` | n 번째 줄로 |
| `Ctrl-d` `Ctrl-u` | 반 화면 아래 · 위 |
| `Ctrl-f` `Ctrl-b` | 한 화면 아래 · 위 |
| `%` | 짝이 되는 괄호로 |
| `fx` `tx` | 줄 안에서 글자 x 로 · x 바로 앞으로 (`Fx` `Tx` 는 왼쪽) |
| `;` `,` | 마지막 f/t 를 같은 방향 · 반대 방향으로 반복 |

## 편집

| 키 | 뜻 |
| --- | --- |
| `i` `a` | 커서 앞 · 뒤에서 입력 |
| `I` `A` | 줄 처음 · 줄 끝에서 입력 |
| `o` `O` | 아래 · 위에 새 줄을 만들고 입력 |
| `x` `X` | 커서 글자 · 앞 글자 삭제 |
| `dd` | 줄 삭제 (잘라내기) |
| `dw` `D` | 단어 삭제 · 줄 끝까지 삭제 |
| `yy` `yw` | 줄 복사 · 단어 복사 |
| `p` `P` | 커서 뒤 · 앞에 붙여넣기 |
| `u` `Ctrl-r` | 되돌리기 · 다시 실행 |
| `.` | 마지막 편집 반복 |
| `cw` `cc` `C` | 단어 · 줄 · 줄 끝까지 지우고 입력 |
| `rx` `R` | 글자 하나를 x 로 · 덮어쓰기 모드 |
| `J` | 아래 줄을 현재 줄 끝에 붙인다 |
| `~` | 대소문자 바꾸기 |
| `>>` `<<` | 들여쓰기 · 내어쓰기 |
| `diw` `ci"` `dap` | 텍스트 객체: 단어 · 따옴표 안 · 문단 (`i` 는 안쪽, `a` 는 둘레 포함) |

## visual 모드

| 키 | 뜻 |
| --- | --- |
| `v` `V` `Ctrl-v` | 글자 · 줄 · 블록 선택 시작 |
| `d` `y` `c` | 선택 영역 삭제 · 복사 · 지우고 입력 |
| `>` `<` | 선택 영역 들여쓰기 · 내어쓰기 |
| `I` `A` | 블록 선택 뒤 여러 줄의 앞 · 뒤에 같은 글 입력 (Esc 로 적용) |
| `gv` | 마지막 선택 영역 다시 선택 |

## 검색 · 치환

| 명령 | 뜻 |
| --- | --- |
| `/패턴` `?패턴` | 아래쪽 · 위쪽으로 검색 |
| `n` `N` | 다음 · 이전 결과 |
| `*` `#` | 커서 아래 단어를 아래쪽 · 위쪽으로 검색 |
| `:%s/a/b/g` | 파일 전체에서 a 를 b 로 모두 치환 |
| `:5,10s/a/b/g` | 5~10 줄에서 치환 (`'<,'>` 는 visual 선택 범위) |
| `:%s/a/b/gc` | 하나씩 물어보며 치환 (y/n/a/q) |
| `/패턴\c` | 대소문자 구분 없이 검색 |
| `:noh` | 검색 강조 끄기 |

## 파일 · 창 · 탭

| 명령 | 뜻 |
| --- | --- |
| `:e 파일` | 파일 열기 |
| `:ls` | 열린 버퍼 목록 |
| `:bn` `:bp` | 다음 · 이전 버퍼 (`:b 번호` 로 바로 이동) |
| `:sp` `:vs` | 가로 · 세로로 창 나누기 (`:sp 파일` 은 열면서 나누기) |
| `Ctrl-w h j k l` | 창 사이 이동 |
| `Ctrl-w q` | 현재 창 닫기 |
| `:tabnew 파일` | 새 탭으로 열기 |
| `gt` `gT` | 다음 · 이전 탭 |

## 저장 · 종료

| 명령 | 뜻 |
| --- | --- |
| `:w` | 저장 (`:w 이름` 은 다른 이름으로) |
| `:q` | 종료 (바뀐 내용이 있으면 거부) |
| `:q!` `ZQ` | 저장하지 않고 종료 |
| `:wq` `:x` `ZZ` | 저장하고 종료 (`:x` 와 `ZZ` 는 바뀐 때만 쓴다) |
| `:qa` `:wqa` | 모든 창 종료 · 모두 저장하고 종료 |
| `:w !sudo tee %` | 읽기 전용으로 연 파일을 sudo 로 저장 |

## 유용한 명령

| 명령 | 뜻 |
| --- | --- |
| `:set nu` `:set nonu` | 줄 번호 켜기 · 끄기 (`:set rnu` 는 상대 번호) |
| `:set paste` | 붙여넣기 때 자동 들여쓰기 끄기 (끝나면 `:set nopaste`) |
| `:set list` | 탭과 줄 끝을 기호로 표시 (`:set nolist`) |
| `:r 파일` | 파일 내용을 커서 아래에 넣기 |
| `:r !cmd` | 명령 출력을 커서 아래에 넣기 (`:r !date`) |
| `:!cmd` | 셸 명령 실행 (`:!ls`) |
| `:%!jq .` | 파일 전체를 명령에 넣고 출력으로 바꾸기 (JSON 정리) |
| `:g/패턴/d` | 패턴이 있는 줄 모두 삭제 |
| `:v/패턴/d` | 패턴이 없는 줄 모두 삭제 |
| `:sort` `:sort u` | 줄 정렬 · 중복을 지우며 정렬 |

## 레지스터 · 마크 · 매크로

| 키 | 뜻 |
| --- | --- |
| `"ayy` `"ap` | 레지스터 a 에 줄 복사 · a 의 내용 붙여넣기 |
| `"+y` `"+p` | 시스템 클립보드로 복사 · 붙여넣기 (`:reg` 로 내용 확인) |
| `ma` | 현재 위치를 마크 a 로 저장 |
| `'a` `` `a `` | 마크 a 의 줄 · 정확한 위치로 이동 |
| `qa … q` | 매크로 a 녹화 시작 … 녹화 끝 |
| `@a` `@@` | 매크로 a 실행 · 마지막 매크로 다시 실행 (`10@a` 는 10 번) |

여러 줄 앞에 같은 글자를 넣는 두 가지 방법:

```vim
" 10~20 줄 앞에 "# " 붙이기
:10,20s/^/# /

" 블록 선택으로 같은 일 하기
Ctrl-v → 10j → I → "# " 입력 → Esc
```

# sed 치트시트

sed 는 입력을 줄 단위로 읽어 바꾸고 출력하는 스트림 편집기다.

기본으로 모든 줄을 출력한다. `-n` 을 주면 `p` 로 고른 줄만 출력한다. 아래는 GNU sed 기준이다.

## 기본 꼴

```bash
sed 's/old/new/' 파일              # 각 줄의 첫 old 만
sed 's/old/new/g' 파일             # 줄의 모든 old
sed -n '5p' 파일                   # 5 번째 줄만 출력
sed -i.bak 's/old/new/g' 파일      # 파일 제자리 수정, 원본은 .bak
sed -e 's/a/b/' -e 's/c/d/' 파일   # 명령 여럿
```

| 옵션 | 뜻 |
| --- | --- |
| `-n` | 자동 출력 끄기 (`p` 로 고른 줄만 출력) |
| `-e 스크립트` | 스크립트 여럿을 순서대로 |
| `-f 파일` | 스크립트를 파일에서 읽기 |
| `-E` | 확장 정규식 ERE (`-r` 과 같다) |
| `-i` | 파일 제자리 수정 |
| `-i.bak` | 제자리 수정 + 원본을 .bak 로 보관 (macOS 는 `-i ''` 가 필요) |
| `-z` | 줄 구분을 NUL 로 (여러 줄에 걸친 치환) |

## 주소

명령 앞에 붙여 적용할 줄을 고른다. 비우면 모든 줄이다.

| 주소 | 뜻 |
| --- | --- |
| `5` | 5 번째 줄 |
| `$` | 마지막 줄 |
| `/패턴/` | 패턴에 맞는 줄 (`/패턴/I` 는 대소문자 무시) |
| `1,5` | 1~5 줄 |
| `5,$` | 5 줄부터 끝까지 |
| `/a/,/b/` | a 가 나온 줄부터 b 가 나온 줄까지 |
| `5,+3` | 5 줄부터 3 줄 더 |
| `1~2` | 1 줄부터 2 줄마다 (홀수 줄, `0~3` 은 3 의 배수) |
| `주소!` | 주소에 맞지 않는 줄 (`5!d` 는 5 줄만 남긴다) |

## 명령

| 명령 | 뜻 |
| --- | --- |
| `s/a/b/` | a 를 b 로 치환 |
| `p` | 줄 출력 (`-n` 과 함께 쓴다) |
| `d` | 줄 삭제 |
| `i\텍스트` | 줄 앞에 텍스트 삽입 |
| `a\텍스트` | 줄 뒤에 텍스트 추가 |
| `c\텍스트` | 줄을 텍스트로 바꾸기 |
| `y/abc/xyz/` | 글자를 하나씩 대응해 바꾸기 (a→x, b→y, c→z) |
| `=` | 줄 번호 출력 |
| `q` | 출력하고 종료 (`5q` 는 앞 5 줄) |
| `N` | 다음 줄을 읽어 현재 줄에 `\n` 으로 붙이기 |
| `D` | 붙인 줄 가운데 첫 줄만 삭제하고 다시 시작 |
| `P` | 붙인 줄 가운데 첫 줄만 출력 |
| `h` `H` | 현재 줄을 보관 공간에 복사 · 덧붙이기 |
| `g` `G` | 보관 공간을 현재 줄로 가져오기 · 덧붙이기 |
| `x` | 현재 줄과 보관 공간 맞바꾸기 |
| `{ … }` | 명령 묶기 (`/a/{s/x/y/;p}`) |
| `;` | 명령 구분 (`-e` 를 여러 번 쓰는 것과 같다) |

## s 명령 자세히

| 꼴 | 뜻 |
| --- | --- |
| `s/a/b/g` | 줄의 모든 a |
| `s/a/b/2` | 줄의 2 번째 a 만 (`2g` 는 2 번째부터 모두) |
| `s/a/b/i` | 대소문자 구분 없이 |
| `s/a/b/p` | 치환한 줄 출력 (`-n` 과 함께) |
| `s/a/b/w 파일` | 치환한 줄을 파일에 쓰기 |
| `s\|/usr\|/opt\|` | 구분자를 바꾸면 `/` 를 그대로 쓴다 |
| `s/.*/[&]/` | `&` 는 일치한 전체 |
| `s/\(a\)\(b\)/\2\1/` | `\1` `\2` 는 괄호 묶음 (BRE 는 괄호에 `\` 가 필요) |
| `sed -E 's/(a)(b)/\2\1/'` | ERE 에서는 괄호를 그대로 쓴다 |
| `s/\w\+/\U&/` | `\U` 대문자화, `\L` 소문자화, `\u` 첫 글자만 |

## 자주 쓰는 한 줄

| 명령 | 뜻 |
| --- | --- |
| `sed -n '10p' 파일` | 10 번째 줄 |
| `sed -n '10,20p' 파일` | 10~20 줄 |
| `sed -n '$p' 파일` | 마지막 줄 |
| `sed '1d' 파일` | 첫 줄 삭제 (헤더 제거) |
| `sed '10,20d' 파일` | 10~20 줄 삭제 |
| `sed '/^$/d' 파일` | 빈 줄 삭제 |
| `sed '/^\s*$/d' 파일` | 공백만 있는 줄도 삭제 |
| `sed 's/[[:space:]]*$//' 파일` | 줄 끝 공백 제거 |
| `sed 's/^[[:space:]]*//' 파일` | 줄 앞 공백 제거 |
| `sed -e 's/#.*//' -e '/^$/d' 파일` | 주석 제거 뒤 빈 줄 제거 |
| `sed -i 's/old/new/g' 파일` | 파일 제자리 바꾸기 |
| `sed -i.bak 's/old/new/g' 파일` | 바꾸고 원본 보관 |
| `sed '3s/old/new/' 파일` | 3 번째 줄에서만 치환 |
| `sed '/start/,/end/s/old/new/g' 파일` | 두 패턴 사이에서만 치환 |
| `sed '/패턴/i\새 줄' 파일` | 패턴 줄 앞에 삽입 |
| `sed '/패턴/a\새 줄' 파일` | 패턴 줄 뒤에 추가 |
| `sed '1i\#!/bin/bash' 파일` | 첫 줄 앞에 삽입 |
| `sed '$a\끝' 파일` | 파일 끝에 추가 |
| `sed 's/.*/\U&/' 파일` | 줄 전체 대문자화 |
| `sed 'N;s/\n/ /' 파일` | 두 줄씩 한 줄로 |
| `sed 's/\r$//' 파일` | CRLF → LF (`s/$/\r/` 는 반대) |
| `sed -n '/패턴/=' 파일` | 패턴이 있는 줄의 번호만 |
| `sed '5q' 파일` | 앞 5 줄 (head -5) |
| `sed '1!G;h;$!d' 파일` | 줄 순서 뒤집기 (tac) |
| `sed "s/HOST/$HOST/" 파일` | 셸 변수 넣기 (큰따옴표) |
